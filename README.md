# Planner Simple

**Индикатор сложности школьного расписания** — облегчённая версия Planner для старых устройств и браузеров, в том числе Safari на iOS 6.

## Возможности

- Расписание на всю неделю: уроки, кружки и домашние задания.
- Оценка сложности каждого дела по шкале от 1 до 10.
- Расчёт общей нагрузки дня и отображение результата на круговой диаграмме.
- Просмотр недельной нагрузки.
- Настройки внешнего вида: светлая и тёмная темы, выбор акцентного цвета.
- Учёт погоды для выбранного города.
- Учёт продолжительности сна.
- Настройка строгости оценки нагрузки.
- Добавление времени начала урока в формате `ЧЧ:ММ`.
- Автоматическая сортировка уроков по времени начала.
- Импорт и экспорт расписания в CSV.
- Создание и восстановление резервной копии в JSON.
- Сохранение расписания и настроек в памяти браузера.

## Как пользоваться

1. Откройте сайт и выберите день недели.
2. Добавьте урок, кружок или домашнее задание.
3. Укажите название, длительность и сложность.
4. Для урока при необходимости укажите время начала. Уроки с указанным временем будут расположены по порядку.
5. Откройте настройки, чтобы выбрать тему, город, параметры сна и строгость расчёта.

## Перенос расписания

Данные хранятся локально в браузере на устройстве.

- **CSV** — для обмена списком дел с другими таблицами и версиями планера.
- **JSON** — для резервного копирования расписания и настроек. Создайте копию, скопируйте полученный текст и сохраните его. На другом устройстве вставьте этот текст в поле JSON и выберите восстановление.

При восстановлении JSON текущее расписание заменяется данными из резервной копии. Перед восстановлением убедитесь, что сохранили нужные текущие данные.

## Совместимость

Planner Simple специально использует более старый и простой JavaScript и стандартные HTML-элементы, чтобы работать в старых браузерах.

Некоторые возможности современных браузеров на старых устройствах недоступны:

- Автоматическое переключение темы по системным настройкам может не работать, если браузер не поддерживает соответствующий API.
- Погодный сервис может не загружаться из-за ограничений старого браузера при работе с современными HTTPS-соединениями.
- Современные функции PWA и Service Worker не поддерживаются Safari на iOS 6.
- Полная версия MarkIt пока не встроена в Planner Simple.

Это ограничения совместимости, а не отключённые пункты интерфейса. Основные функции расписания и локального хранения рассчитаны на работу без современных возможностей браузера.

## Техническая информация

Проект сделан как одна HTML-страница: разметка, CSS и JavaScript находятся в файле `index.html`. Это упрощает размещение на GitHub Pages и помогает сохранить совместимость со старым браузером.

Данные расписания и настройки сохраняются в `localStorage` браузера. Они не отправляются на сервер проекта.

---

Planner Simple — отдельная облегчённая версия. Изменения в основном Planner не обязаны автоматически появляться в Planner Simple.
